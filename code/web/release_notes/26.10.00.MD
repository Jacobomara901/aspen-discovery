#### Omeka
- Add an Omeka module that indexes items from an Omeka S or Omeka Classic server directly through its REST API. Only the item sets and collections referenced by scopes are extracted from the server. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
- Add Omeka Settings and Scopes administration pages. Settings define the Omeka version, server connection, API keys, and site slug. Scopes include all item sets or a list of Omeka S item sets / Omeka Classic collections; each library and location can include multiple scopes. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
- Add an Administer Omeka permission granting access to the Omeka administration pages. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
- Show Omeka items as always available online eContent that links to the public item page on the Omeka site. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
- Add an Omeka Export Log to review extractions from Omeka. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
- Extract changed items every five minutes, sweep all items once a day for deletions, and load media in bulk during a full update. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
- Give each Omeka item its own grouped work. A setting groups items that share a title, author, and format instead. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
