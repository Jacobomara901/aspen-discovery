### BorrowBox Integration
- Added a BorrowBox module that harvests the library's BorrowBox catalogue into the index, so eBooks, eAudiobooks and eMagazines appear in search results grouped with print editions and show current availability. ([DIS-2276](https://aspen-discovery.atlassian.net/browse/DIS-2276)) (*JOM*)
- Patrons can borrow, reserve, renew and return BorrowBox titles from within Aspen and see them in their account with an Open in BorrowBox link; usage is tracked daily and respects analytics opt-out. ([DIS-2276](https://aspen-discovery.atlassian.net/browse/DIS-2276)) (*JOM*)
- Added BorrowBox settings with audience-level scopes, per-library Site IDs, a usage dashboard with graphs and CSV export, and an indexing log, gated by a new Administer BorrowBox permission. ([DIS-2276](https://aspen-discovery.atlassian.net/browse/DIS-2276)) (*JOM*)

### Language and Translation Updates
- Language selection confirmation popups now display in the newly selected language instead of the previously active language. ([DIS-2683](https://aspen-discovery.atlassian.net/browse/DIS-2683)) (*YL*)
- My Account language preference update messages now display in the user’s newly selected language. ([DIS-2683](https://aspen-discovery.atlassian.net/browse/DIS-2683)) (*YL*)

### Series Updates
- Fix an issue where grouped work series names could display with lowercase when series data came from MARC records. ([DIS-2689](https://aspen-discovery.atlassian.net/browse/DIS-2689)) (*YL*)
